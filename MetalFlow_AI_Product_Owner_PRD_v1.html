01 产品定位与执行摘要

MetalFlow AI 不是普通 AI SDR，也不是自动群发获客工具，而是面向金属贸易公司的 SaaS 工作空间，帮助管理客户关系、动态报价、外贸文件和订单流程。

核心目标：维护既有客户关系、提高报价效率与准确性、将散落在 Excel、Email、WhatsApp、LinkedIn 中的信息组织成可追溯的业务流程。

Excel 导入 → Customer 360 → Email / WhatsApp 沟通 → AI 总结与客户记忆 → 动态报价 → PDF Quotation → 人工审批 → 客户跟进 → Order Management

03 核心业务流程

Customer Lifecycle

沟通采集 → Customer 360 → AI Relationship Assistant → 业务员维护关系
  • 客户档案：采购历史、沟通历史、产品规格偏好、报价记录、付款习惯、跟进事项。
  • Customer Relationship Brief：历史采购、最近沟通、偏好及下一步建议。
  • 自动总结邮件、生成回复草稿、提醒跟进；对外发送由人确认。
  • 身份解析：Email、电话、LinkedIn URL、域名、公司名称；疑似同名公司人工确认，不自动合并。
  • 不自动承诺价格、库存、交期、账期，不自动处理重大客诉和信用决策。

Quotation Lifecycle

RFQ → 规格校验 → 工厂报价 → 行情与汇率参考 → 成本利润计算 → 审批 → PDF → 跟进
  • 支持四种金属产品及 FOB/CIF/CFR。市场参考价不等于真实工厂成本。
  • 确定性 Pricing Engine 负责金额计算；LLM 负责解析、解释和风险提示。
  • 报价快照保存供应商成本、行情来源、汇率、运费、保险、其他费用、利润、Incoterm、币种、有效期及时间戳。历史报价不得按最新行情重算。
  • 报价单生成可自动化，发送前必须人工审批。

计算逻辑示意：总成本 = 货物成本 + 适用物流费用 + 适用保险 + 其他费用；若采用销售额毛利率 m，售价 = 总成本 / (1 − m)。实际费用归属、单位、汇率和利润口径需业务确认。

Order Lifecycle

报价接受 → PI / 合同草稿 → 付款条款批准 → 预付款核实 → 工厂备货 → QC → 装运 → 单据 → 尾款核实 → 交付 → 售后

初期仅做报价转订单、PI/合同草稿、订单状态、付款节点和交货提醒。不开发完整报关、物流和银行集成。到账必须依据可信记录，合同由人签署。

05 Agent Architecture

User → Orchestrator → Customer / Market / Quotation / Document Agents → Controlled Tools → Human Approval
Agent职责
Customer Intelligence客户理解、邮件总结、客户记忆、下一步建议

  • 所有租户业务表具备 tenant_id；应用层与数据库层双重隔离，考虑 PostgreSQL RLS。

角色权限边界

12 AWS 部署方案

Users → TLS / WAF / ALB → Frontend + FastAPI (ECS Fargate) → Private RDS PostgreSQL / S3 / Queue → AI Provider
  • Frontend / Backend：ECS Fargate；App Runner 等替代方案需确认新项目可用性，Vercel 需满足数据要求。
  • RDS PostgreSQL private subnet；ElastiCache（需要 Celery 时）；S3 SSE-KMS、按租户授权路径。
  • Secrets Manager / SSM Parameter Store；OAuth token 加密，不在源码保存凭据。
  • VPC、Security Groups、WAF、ALB、Route 53、ACM。
  • CloudWatch logs / metrics / alarms；RDS PITR、S3 versioning/lifecycle。
  • GitHub Actions → ECR → ECS；生产前隔离渗透测试、备份恢复、事件响应、隐私及数据删除流程。

跨境数据处理、客户所在地及中国业务访问体验需验证后确定 AWS Region。暂不承诺具体云成本。

14 给公司老板的产品介绍

让金属外贸业务从 Excel 和零散沟通走向智能化管理

公司现在最有价值的资产，不只是工厂资源，还有多年积累的客户关系、报价经验和业务员对客户需求的理解。但这些信息往往散落在 Excel、邮箱和聊天记录里。人员交接时容易丢失，管理层也很难及时掌握每个客户和订单的进展。

MetalFlow AI 不是替代业务员，而是给每个业务员配备一个智能助理，并把业务经验沉淀为公司资产。

一个实际工作场景

一位欧洲老客户发邮件询问镁锭。系统自动整理他的历史采购规格、上次报价和最近沟通。业务员输入工厂最新成本，系统结合贸易条款和费用计算利润，生成正式报价单草稿。经理确认后，业务员发送报价。客户接受后，系统建立订单，提醒预付款、备货、装运和尾款节点。

公司能得到什么？

  • 客户资料和历史经验不再只掌握在个人手中。
  • 减少重复整理邮件、计算价格和制作报价单的时间。
  • 降低错报、漏报和忘记跟进的风险。
  • 管理层更清楚客户、报价和订单的实际状态。
  • 未来可将成熟系统提供给其他金属贸易公司，形成 SaaS 收入。

怎样低风险开始？

先选两三位业务员和少量老客户试用，不要求一次性改变全公司流程。保留 Excel 导入，报价、合同和关键承诺仍由人确认。根据实际节省时间、错误率和客户跟进效果决定是否推广。

投入与回报

先验证首个企业客户，再考虑按公司、用户或功能套餐收费。ROI 应以开发及运营成本、节省工时、报价速度、错误率和复购数据计算，不提前承诺收益。
